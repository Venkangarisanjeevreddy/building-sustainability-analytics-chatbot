# Smart Building Sustainability Chatbot

## Project Introduction
The Smart Building Sustainability Chatbot is an AI-driven analytical platform designed to improve building sustainability using Data Science, Machine Learning, and intelligent automation. The system analyses operational building data such as occupancy, environmental conditions, and weather metrics to provide predictive insights that support efficient energy management and sustainable building operations.

The platform combines machine learning forecasting models, interactive dashboards, and an AI-powered chatbot interface to help users monitor building performance in real time and make data-driven sustainability decisions.

# Machine Learning Implementation

The system applies supervised regression algorithms to predict occupancy behaviour and improve operational efficiency.

## Models Used

| Algorithm | Function |
|---|---|
| Linear Regression | Baseline analytical model |
| Random Forest | Occupancy prediction |
| XGBoost | High-performance forecasting |

## Performance Metrics

- Low prediction error
